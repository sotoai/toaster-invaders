Xbox Controller

  • Left Stick/D-Pad Move
  • A/RT Fire
  • Start Start · Pause
  • Y Next character
  • Left Stick/D-Pad Browse the nine characters
  • B Back out

Keyboard

  • P1 AD move · Space/W fire · Enter start · Esc back
  • P2 ←→ move · ↑// fire · R-Shift start · Backspace back
  • Mode Co-op shares one board · Classic alternates turns
  • Characters Nine to pick from · left/right browses · each has one advantage and one drawback
  • Weapons Shoot the flying utensil drawer · catch the token it drops · get a weapon

Touch

  • Buttons One player: arrows left, fire right · two players: a cluster each edge
  • Drag Slide anywhere on the screen to steer · tap to fire · toggle with the mode button
  • P2 Tap P2 on the right column to join · each player then owns one edge
  • Pads A paired Xbox or PlayStation controller still works · touch does not replace it

Press a button on each controller to wake it up — browsers do not report a gamepad until it sends input.

No sound? iPad and iPhone route this game through the silent switch — flick Ring/Silent on, or turn Silent Mode off in Control Centre.
